# Операторские команды

Команды импорта, подготовки примеров и ручной работы с кандидатами используют
код `recruiting-api` из родительской папки. Посмотрите `--help` и README сервиса
перед запуском. Это команды работы с данными, а не часть автоматического старта
или тестов. Runtime и настройки действующей системы задаются явно при выпуске.
