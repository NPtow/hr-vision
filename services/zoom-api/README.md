# Zoom API

Закрытый HTTP-адаптер в `app.py`. Сохраняет существующий контракт вызовов Zoom;
авторизация продуктового сценария остаётся в recruiting-api. Настройка задаётся
через окружение, ключи в Git не хранятся.

Поставка с закреплёнными модулями: [упаковщик](../../infra/deployment/services/simple/README.md).
Проверка: `python scripts/check.py services` из корня с установленными Python-
зависимостями. Ответы Zoom подменены тестовым провайдером.
