# Сервисы

| Сервис | Ответственность | Данные и границы |
| --- | --- | --- |
| [recruiting-api](recruiting-api/README.md) | Продуктовый API, авторизация, согласия, встречи и переходы процесса | Существующая HR SQLite и серверные адаптеры. UI обращается к этому API. |
| [data-core](data-core/README.md) | Каталог, привязка и выдача материалов | Существующая HR-база через закреплённый адаптер; это сохранённая совместимость, не отдельная база. |
| [transcription-source](transcription-source/README.md) | Приём записей, координация обработки и доставка результата | Собственная SQLite, API/worker/scheduler; доступ в Core по контракту. |
| [transcription](transcription/README.md) | Распознавание и нормализация текста | Собственные задания и файлы; провайдер задаётся явно. |
| [assessment-core](assessment-core/README.md) | Оценка полного корпуса кандидата | Собственный журнал, очередь и сохранённые ответы. |
| [vacancy-profile](vacancy-profile/README.md) | Получение требований вакансии | Собственная очередь, профили и версии требований. |
| [recommendations](recommendations/README.md) | Детерминированное сопоставление | Собственная SQLite; получает снимки, не читает HR-базу. |
| [employer-review](employer-review/README.md) | Подготовка оценки и цитат для работодателя | Собственные задания; материалы передаёт авторизованный HR API. |
| [interview-agent](interview-agent/README.md) | Ответы по материалам интервью | Ограниченные сессии и заданный набор инструментов чтения. |
| [zoom-api](zoom-api/README.md) | Закрытый HTTP-адаптер Zoom | Провайдерские настройки и разрешённые операции звонка. |
| [assessment](assessment/README.md) | Прежний оценщик | Сохраняется, пока его потребители явно не переведены. |

API, worker и scheduler одной функции остаются в одном проекте. Существующие
упаковщики включают нужные закреплённые зависимости. Перенос не меняет схемы,
протоколы и владение данными. Тесты находятся рядом с кодом; общие сценарии — в
[tests/integration](../tests/integration), упаковщики — в
[infra/deployment/services](../infra/deployment/services).
