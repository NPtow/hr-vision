# Поведенческие шкалы: рабочая версия 1

`analytics-baseline.json`, версия `2026-10-26.behavioral-anchors.1`.
Из существующей аналитики сохранены 16 ID, названия параметров и их определения.
80 описаний и коротких названий уровней разработаны отдельно по этим определениям.
Это наша рабочая интерпретация навыков, а не шкалы, заимствованные из упомянутого
в определениях профстандарта, и не валидированный психометрический инструмент.

Для каждого параметра:

- L1 описывает показанное действие, мешающее решению задачи. Молчание об этом
  навыке не является L1.
- L2 описывает частичное или шаблонное выполнение конкретной задачи.
- L3 описывает самостоятельное выполнение основной задачи параметра.
- L4 описывает работу с причинами, ограничениями и изменяющимися условиями.
- L5 описывает проверку альтернатив, зависимостей или последствий в границах
  того же навыка. Это не требование привести больше эпизодов или руководить
  людьми, если сам параметр не является управленческим.

Названия в карточке также конкретны для параметра. Например, L3 для A06.1 —
«Уточняет и разбирает сомнение», для A06.2 — «Договаривается в заданных границах».
JEV получает полные описания в criteria, определение параметра в instructions
и общий неизменный корпус CV + интервью в state. Модель сама сопоставляет материал
с уровнями; предварительной разметки чанков по параметрам нет.

«Недостаточно данных» остаётся отдельным шестым вариантом, не низкой ступенью.
Управленческие параметры не исключаются автоматически по должности: если
относящихся к ним сведений нет, ожидается именно этот вариант. Источники не
дополняются выдуманными фактами, чтобы получить числовую оценку.

Версия и hash шкалы входят в ID запуска. Изменённые описания требуют новых
ответов модели: прежние вероятности нельзя показывать под новыми формулировками.
Тест shipped rubric защищает от повторного копирования одной шкалы во все
параметры; общий валидатор сохраняет совместимость со старыми планами для replay.

Следующая методологическая проверка — независимая разметка реальных эпизодов,
разбор неоднозначных границ соседних уровней и сравнение с ответами JEV.
Успешный запуск API не подтверждает качество или калибровку шкалы.
