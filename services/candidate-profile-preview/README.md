# Живой просмотр кандидатов

[Открыть отдельный стенд](https://hr-vision.158-160-179-53.sslip.io/candidate-preview/).

В том же браузере, где открыт Верстак, нажмите «Войти через HR Vision». Выберите одного из кандидатов с завершённым записанным интервью в верхнем списке. Нажмите сектор круга навыков: справа появятся сохранённый уровень и описание. «Все 16» раскрывает остальные критерии. «Открыть интервью» показывает полную запись и расшифровку; таймкод переводит запись на соответствующее место. Обновление материалов сохраняет позицию.

Отдельный stateless Python-сервис и React-интерфейс подключены к существующим manager/Core/Source API. Собственной базы кандидатов нет. Публичный просмотр и изменение данных не подключены. Основной кабинет работает отдельно.

## Работа 15 агентов

| Агент | Ответственность |
|---|---|
| 01 | Каталог кандидатов, сессии и права |
| 02 | Контракт сохранённых оценок |
| 03 | API материалов и интервью |
| 04 | Независимый обзор доступа и безопасности |
| 05 | Проверка повторного использования плеера |
| 06 | BFF и адаптер материалов |
| 07 | Интеграционные тесты backend |
| 08 | Клиент API, пагинация и отмена запросов |
| 09 | Каркас профиля, состояния и вкладки |
| 10 | Визуальный слой и шапка |
| 11 | Оценки и валидатор |
| 12 | Плеер и расшифровка |
| 13 | Карта навыков |
| 14 | Упаковка, systemd и эксплуатация |
| 15 | Независимые frontend-регрессии |

Интеграция, выкладка и живые браузерные проверки выполнены главным агентом. Гонки авторизации, удержание материалов после отказа и неверные единицы таймкодов исправлены по результатам проверок.
