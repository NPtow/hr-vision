# Общие библиотеки

- [assessment-contracts](assessment-contracts/README.md): схемы и правила обмена в контуре оценки.
- [web-shared](web-shared/README.md): общая кнопка и переход между сайтом и кабинетом.
- [jev-client](jev-client/README.md): транспорт JEV и проверка ответа.

Библиотека содержит контракт или повторно используемый код. Она не владеет
общей изменяемой базой и не запускает соседние сервисы. Изменение библиотеки
проверяется вместе с потребителями; production-артефакты содержат закреплённую копию.
