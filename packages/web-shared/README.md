# Общий web-код

`button.tsx` — существующая кнопка, используемая кабинетом и публичным сайтом.
`employer-entry.ts` — общий контракт перехода с сайта к регистрации/входу,
включая срок жизни и очистку черновика. Поведение перенесено без изменения.

Пакет входит в корневой npm workspace вместе с `apps/web` и `apps/website`.
Установка: `npm ci` из корня. Общий `package-lock.json` закрепляет зависимости
и единственную React-версию для этой группы. Другие приложения сохраняют свои
независимые lock-файлы.

Проверки перехода находятся в `apps/web/scripts/employer-entry.test.ts` и
выполняются `python scripts/check.py web`; оба приложения проверяются сборкой.
