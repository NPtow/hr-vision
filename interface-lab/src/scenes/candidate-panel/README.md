# Панель кандидатов · HRDS

Три связанные интерфейсные гипотезы: панель, добавление кандидатов, назначение встречи.
Источник: архив `hr-vision-interface-lab.zip` от 07.10.2026 содержит готовую Storybook-сборку, без исходников. Реализация продолжает репозиторий HR Vision и использует React, Radix, shadcn Button и токены HRDS. Задачи и вакансии остаются в работе дизайнера.

Истории: `hr-vision-panel-hrds--panel`, `--add`, `--schedule`.

- Панель: компактный список, поиск, избранное, отложенные, интервью/резюме, таймлайн, фрагменты, расшифровка, заключение и переход к встрече.
- Добавление: файлы резюме, ссылка или ручная карточка. Имя проверяется до добавления. Автоматический парсинг резюме не заявляется. Новым кандидатам не подставляется чужое интервью.
- Встреча: доступные интервалы, длительность, защита от пересечения с другими встречами работодателя, перенос и отмена. Предложенное время имеет статус ожидания, а не подтверждённой встречи. Другие встречи не заменяются.

Вымышленные данные, состояние в памяти текущего просмотра. Нет отправок кандидатам и записи в API. Видеоплеер принимает локальный видеофайл, воспроизводит и переключает временные отметки. Демонстрационные вопросы/цитаты не анализируют загруженное видео. Публичная лаборатория и рабочий сервис разделены.

Roboto Flex получен из официального Google Fonts; лицензия OFL лежит в fonts/RobotoFlex.LICENSE.txt. Motion уважает reduced motion. Интерактивные компоненты содержат имена для screen reader и видимый keyboard focus.
