# Поиск на паузе: орбита / портфель

13 октября 2026. Два локальных варианта HR Vision, `CelebrationOrbit`, `variant=0|1`.

## Решения

- **0 — Всё сошлось.** Шесть маленьких возможностей проходят короткую дугу и собираются в одну карточку результата. Последним появляется знак подтверждения. Орбиты остаются тихой статичной геометрией, а не бесконечным фоном.
- **1 — Всё со мной.** Три цветных листа выстраиваются и уходят в портфель. Клапан складывается, на нём защёлкивается золотистый знак подтверждения. Здесь движение линейное и физическое, в отличие от орбитального варианта.
- Оба входа завершаются менее чем за 1,9 секунды. Иллюстрация — доступная кнопка повторного воспроизведения. `runId` пересоздаёт только сцену анимации; оба основных действия вызывают переданные обработчики сразу и не ждут анимацию.
- При `prefers-reduced-motion` сразу виден конечный результат. Нет циклов, звука, запросов к API и имитации реально принятого оффера.
- Текущий статус и две кнопки остаются в одном месте. После остановки поиска все процессы переходят в историю. «История поиска» открывает их через прежний `onProcesses`; «Снова искать работу» запускает новый поиск через `onResume`.

## Исследование и происхождение

Использованы `apple-design`, `interface-lab`, `context7`. В Context7 выполнены именно два шага:

```text
c7 search motion
→ /websites/motion_dev, trust 9.7
c7 docs /websites/motion_dev "React useReducedMotion SVG motion.g animate keyframes spring visualDuration button whileTap" 3500
```

Проверенная версия в проекте: `motion 13.4.6`. Использованы публичные API `motion/react`, `motion.g`, `useReducedMotion`, `whileTap`.

- [Motion: SVG animation](https://motion.dev/docs/svg-animation) — управление группами и SVG-анимация; отсюда выбраны отдельные `motion.g`, а не видео или тяжёлый canvas.
- [Motion: useReducedMotion](https://motion.dev/docs/react-use-reduced-motion) — переключение на спокойный эквивалент по системному предпочтению.
- [Motion: accessibility](https://motion.dev/docs/react-accessibility) — движение заменяется статичным результатом; доступные названия и клавиатурное управление сохраняются.
- [Apple: Designing Fluid Interfaces](https://developer.apple.com/videos/play/wwdc2018/803/) — причинность, непрерывность, немедленный отклик и контролируемая пружина. Геометрия, цвета, длительности и радиусы здесь являются нашей веб-адаптацией; они не заявляются официальной спецификацией Apple.

SVG нарисован специально для этих макетов. Заимствуется документированный API, не чужая иллюстрация или персонаж. Ассоциация с Duolingo — чувство небольшого достижения; визуальный язык взрослый, бело-синий HR Vision.

## Проверка

В изолированном Vite-просмотре проверены desktop 1000×900 и mobile 390×844. Горизонтального переполнения нет (document width = viewport). В браузере обе CTA вызывают соответствующие обработчики; окончание входа видно без повторяющегося движения. Обе композиции визуально проверены, второй вариант проверен также с системным reduced motion. На обычном входе ошибок и предупреждений в консоли нет. Общий typecheck на момент проверки показал только чужую ошибку `ProfileVariants.tsx:39` (`string | boolean` в `value`); в `CelebrationOrbit.tsx` ошибок не было.
