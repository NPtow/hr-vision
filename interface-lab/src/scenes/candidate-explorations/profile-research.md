# Профиль после интервью: десять интерактивных вариантов

2026-10-13. Реализовано в `ProfileVariants.tsx` и `profile.css`. Здесь только содержимое профиля; вход через аватар, навигация, данные и эффект прекращения поиска принадлежат общей оболочке. `save(profile)` передаёт сохранённые изменения наверх. Backend не подключён.

| variant | Организация | Основное взаимодействие |
|---|---|---|
| 0 | Читаемый документ | Группа раскрывается для inline-редактирования; можно включить редактирование всего документа. |
| 1 | Сгруппированные настройки | Нажатие строки группы заменяет сводку компактной формой внутри той же группы. |
| 2 | Карточка человека + условия | Личные данные и связь находятся в левой карточке; основной текст и условия — в правой колонке. |
| 3 | Профиль рядом с формой | Слева живое представление текущего draft, справа все поля; сохранение и отмена доступны внизу формы. |
| 4 | Аккордеон | Одновременно раскрыт один раздел; читать и редактировать можно внутри раскрытой секции. |
| 5 | Bento | Разные размеры смысловых блоков: крупный текст о себе, зарплата, идентичность и широкая связь. Каждая плитка редактируется на месте. |
| 6 | Список разделов + редактор | Локальный список переключает одну рабочую область. Это навигация по группам открытого профиля, не новая глобальная навигация приложения. |
| 7 | Узкая личная страница | Центрированная идентичность, длинная вертикальная страница, чтение и отдельные правки блоков. |
| 8 | Личные данные / поиск работы | Два сегмента разделяют личные сведения и условия с каналами связи; клавиши стрелок перемещаются между сегментами. |
| 9 | Компактная сводка + панель | Нажатие карточки открывает редактирование нужной группы в выдвижной панели. Escape / закрытие отменяет draft, фокус возвращается к исходной карточке. |

Во всех вариантах верхняя карточка «Ищу работу» меняет draft.searching и предлагает сохранить либо отменить. При выключении показано: «При остановке поиска все процессы уйдут в историю». Сам компонент не меняет вакансии или встречи — передаёт `searching: false` через `save`; перенос процессов в историю выполняет root по последнему решению пользователя.

Редактируются имя, должность, город, район/метро, текст о себе из резюме, диапазон зарплаты, занятость и дата выхода. Telegram и автосогласование симулируются в draft. Автосогласование не включается самим компонентом; исходное false приходит из root. Пояснение о самостоятельном подтверждении времени встреч присутствует в чтении и редактировании. Внутренних рекрутерских данных, рейтингов, согласия на интервью, загрузки CV и онбординга здесь нет.

## Основания компоновки

Применён `interface-lab/SKILL.md` и прочитана карта текущей лабы. Эта реализация находится в HR Vision `interface-lab`, не в историческом пути Proteus из карты. Сохраняются React / TypeScript / настоящий Storybook, отдельная сцена, локальная симуляция и изолированные CSS-классы `cex-profile*`.

Из предыдущего исследования сохраняются конкретные ориентиры:

- [Apple Account](https://support.apple.com/guide/iphone/sign-in-and-manage-your-apple-account-iph76e54c61e/ios): идентичность отдельно, смысловые группы и понятное редактирование. Применено в 1, 2, 6 и 8.
- [Telegram Login](https://core.telegram.org/bots/telegram-login): отдельные разрешения и ясно названное действие. Применено к независимым Telegram / автосогласованию / статусу поиска, без копирования протокола авторизации.
- [Apple WWDC25](https://developer.apple.com/videos/play/wwdc2025/356/): согласование радиусов и отступов, смысловая группировка. Белые поверхности, Inter, радиусы и синий акцент — решения HR Vision, а не заявленная копия Apple.

## Сохранение и проверка

Общий draft отделён от profile root. Save обрезает пробелы, проверяет обязательные имя/должность/город/занятость, положительные целые границы зарплаты, порядок диапазона и дату. Ошибка переносит в нужную группу и фокусирует поле; Cancel возвращает сохранённые значения. Данные остаются общими при переключении экранов после save. Несохранённый draft живёт только внутри профиля.

Контейнерная адаптация использует именно `@container cex-product (max-width:700px)` и дополнительный порог 440px. Формы, split layout и bento складываются вертикально. Drawer реализован через Radix Dialog с фокусом и Escape внутри поверхности профиля.

Проверено: `npm run typecheck` прошёл. Визуальная и интерактивная проверка общей Storybook-истории выполняется после регистрации оболочки; эта запись не утверждает её прохождение заранее. Сборка, публикация и реальные интеграции данным изменением не выполнялись.
