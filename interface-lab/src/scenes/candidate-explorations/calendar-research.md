# Календарь кандидата · 10 интерактивных вариантов

Дата: 13.10.2026. Реализация ограничена `CalendarVariants.tsx` и `calendar.css`. Shell, сценарии, вакансии, профиль, Storybook и общие события принадлежат родительской сцене. Календарь = встречи + собственная доступность; даты макета — октябрь 2026, зона — Москва UTC+3.

## Различия компоновок

| variant | Композиция | Для какой задачи |
|---|---|---|
| 0 | Месяц с событиями + постоянная повестка выбранного дня | Видеть целиком месяц и сразу читать детали выбранного дня |
| 1 | Семь колонок недельной почасовой сетки | Сопоставлять занятость и собственные интервалы доступности |
| 2 | Группы по датам, слева дата, затем время и карточка | Быстро просматривать небольшое число встреч |
| 3 | Вертикальная полоса дней + один выбранный день | Сосредоточиться на дне, сохранив быстрый переход по неделе |
| 4 | Маленький месяц в боковой колонке + сетка карточек | Сканировать подробные встречи с фильтром по дню / всему месяцу |
| 5 | Две горизонтальные недели, самостоятельные плитки дней | Планировать следующие две недели и видеть интервалы доступности |
| 6 | Вертикальная хронология и переключение upcoming/history | Читать последовательность встреч и возвращаться к истории |
| 7 | Два независимо переключаемых дня с часовыми шкалами | Сравнить два дня при согласовании времени |
| 8 | Пять строк недели с горизонтальными интервалами доступности + agenda | Редактировать удобное время и видеть назначенные встречи внутри него |
| 9 | Крупная ближайшая встреча + полоса недели и компактный список | Быстро подтвердить время или войти в ближайшую встречу |

Это не десять цветовых тем: DOM/сетка, масштаб времени, плотность и расположение выбранной встречи различаются. Палитра и типографика едины: белая поверхность, синий акцент, Inter, lucide-react.

## Реальные локальные действия

- Переходы по месяцам/неделям, возврат к 19 октября («Сегодня» в данных макета), выбор даты, открытие деталей, переход к конкретной вакансии.
- `act(id, 'confirm' | 'reschedule' | 'join')` не создаёт параллельный state. Изменённые вакансии сразу приходят от родителя.
- Доступность 19–23 октября редактируется в раскрываемой секции. Checkbox управляет днём; time inputs — интервалом; «Сохранить» проверяет `to > from`, вызывает `setAvailability`, показывает результат. «Отмена» и Escape отбрасывают draft. Фокус возвращается к кнопке.
- Предстоящие встречи = `proposed/confirmed` и `archived !== true`. История строится по отдельным событиям `JourneyEvent.kind=meeting_completed` с сохранёнными `day/time`; fallback — legacy-событие `Встреча состоялась` и стадии `completed/followup/offer/accepted`. Архивные предложенные/подтверждённые встречи добавляются отдельно. Несколько завершённых встреч одной вакансии сохраняются независимо от текущей стадии.
- Архивное предложение времени не названо состоявшейся встречей; оно без кнопок подтверждения/входа/переноса. Если состоялась предыдущая встреча и уже предложена следующая, новая остаётся рабочей, а история не подставляет её новое время вместо прошлого.
- История доступна во всех вариантах. Кнопка «О вакансии» использует `openVacancy(id)` — родитель выбирает правильную вкладку и запись.
- Month/date rail поддерживают стрелки; month дополнительно Home/End/PageUp/PageDown. Кнопки имеют focus-visible; состояния отмечены `aria-pressed`; результат сохранения — `role=status`, ошибки — `role=alert`.
- `useReducedMotion` отключает смещение и длительность Motion; CSS reduced-motion убирает переходы. Нет циклической анимации, автопрокрутки или таймеров.

## Прочитанные skills и реальный Context7

Применены interface-lab, context7 и motion; проверены локальные Motion best practices для React. Путь текущей лабы проверен по checkout; исторический адрес Proteus из skill не использовался.

Выполнено:

```text
c7 search "motion react"
→ /websites/motion_dev_react
c7 docs /websites/motion_dev_react "useReducedMotion AnimatePresence exit transitions" 1800

c7 search "react aria calendar"
→ /websites/react-aria_adobe
c7 docs /websites/react-aria_adobe "Calendar keyboard navigation selected focused dates" 2000
```

Источники:

- [React Aria Calendar](https://react-aria.adobe.com/Calendar) — раздельные понятия выбранной/сфокусированной даты, управление фокусом, клавиатурный календарь. В макете применены паттерны к простым семантическим кнопкам; библиотека React Aria не добавлялась.
- [React Aria FocusScope](https://react-aria.adobe.com/FocusScope) — стрелки и Home/End для группы. Здесь локальный ref ограничивает поиск кнопок конкретной полосой дат.
- [Motion accessibility](https://motion.dev/docs/react-accessibility), [useReducedMotion](https://motion.dev/docs/react-use-reduced-motion) — лёгкие opacity/position входы с reduced-motion веткой; импорт из `motion/react`, установленная версия 13.4.6.
- [Cal.com booking UI](https://cal.com/embed) — связка календаря с контекстом выбранного времени; платформенный SDK не подключался.
- [Google Meet: meeting resources](https://workspaceupdates.googleblog.com/2026/07/a-centralized-hub-for-meeting-resources-on-the-new-Google-Meet-homepage.html) — связь конкретной встречи с действием входа и материалами.

Все численные размеры, отступы и радиусы — решения этого веб-макета. Они не объявлены универсальными токенами Apple. Материалы и источники исследования календаря подробнее в `planning/candidate-cabinet-2026-10-13/references/schedule.md`.

## Проверка и ограничения

`npm run typecheck` после создания компонентов и CSS прошёл. CSS изолирован префиксом `cex-calendar`, есть `@container cex-product` для 1000/700/430 px и media fallback. Попытки открыть Storybook через CUA с `iab` и `chrome` вернули `Browser not available`; фактический визуальный прогон в общей Storybook-сцене остаётся проверкой родительской задачи; этот файл не заявляет успешной публикации или browser E2E. Никакого network backend, установки зависимостей, коммита или deployment не сделано.
