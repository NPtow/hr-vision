# Публикация и происхождение

## Текущее состояние

На 02.10.2026 прежние экраны и актуальные пять CJM опубликованы на `https://proteus-lab.158-160-179-53.sslip.io`. Релиз `20261002T115519Z-26110`, предыдущий `20261002T111630Z-6184`. Создание этого репозитория не требует повторной публикации уже доступной версии.

Активные исходники взяты из staging, использованного для этого релиза. SHA-256 оригинальных 23 файлов сохранены в `import-manifest.json`. При выделении в репозиторий изменена только ссылка «interface lab» в `HRVisionLab.tsx`: она открывает HR Vision вместо общей галереи Proteus. Оболочка Storybook получила имя HR Vision; скопированы общий reset и правило reduced motion, остальные чужие стили исключены. Сами экраны и содержание последних CJM сохранены.

Историческая v3 импортирована отдельно и помечена архивом. Промежуточные неопубликованные исправления общей лаборатории не включены.

## Самостоятельная сборка

`npm ci`, `npm run typecheck`, `npm run build` из этой папки. Результат в `storybook-static/` можно разместить на любом статическом хостинге в корне сайта. Бэкенд, переменные окружения и ключи не требуются.

## Обновление прежнего общего адреса

На этом адресе живут и другие прототипы. Нельзя заменять весь сайт сборкой только HR Vision: это удалит их из каталога. Поэтому опасный скрипт полной перезаписи общей лаборатории в этот репозиторий не перенесён.

Для обновления общего сайта нужно перенести выбранные HR-файлы в изолированную сборку полной лаборатории, проверить список изменений, собрать все истории и использовать существующий атомарный выпуск общей лаборатории. На YC каталог `/srv/proteus-storybook/releases/`, указатели `current` и `previous`; штатный выпуск не требует перезапуска Caddy или других приложений. После публикации проверить index.json, ресурсы и переходы по прежним адресам.

Секреты и SSH-ключи в репозиторий не входят. Автоматическая публикация по push пока не настроена.
