# Кандидаты ДСА в HR Vision

Запрос: подключить кандидатов из существующей панели ДСА Инжиниринг на YC.

Источник: `kabinet.158-160-179-53.sslip.io`, `/opt/kabinet`, отдельный действующий `kabinet.service` на dsa. Проверено 06.10.2026: API отдаёт 6 профилей, все 6 video endpoints поддерживают HTTP 206 и byte ranges. Исходная вакансия: «Менеджер по работе с клиентами».

## Реализация

В кабинете работодателя добавлена отдельная задача «ДСА Инжиниринг». Текущий сценарий «Сфера», три тестовых кандидата и весь прогресс остаются отдельно. Эта граница выбрана по умолчанию; вопрос о полном тестовом пути от лица реальных кандидатов отправлен пользователю отдельно.

Данные читаются сервером outreach через GET, не зашиваются в публичную сборку. `dsa_panel.py` переводит только разрешённые поля исходного API. Доступ к новому endpoint требует сессию работодателя. Кандидатские роли и анонимный запрос получают отказ. Сетевой запрос не блокирует SQLite сценария.

Внутри профиля: реальная запись интервью, короткая версия с автоматическими переходами по исходным фрагментам, полное интервью с главами, цитата/описание выбранного момента, оценка и заключение рекрутера, вопросы к следующему разговору, профиль и исходное резюме. Описание главы не выдаётся за прямую цитату. Статусы подписаны «В ДСА».

Видео читается через действующий источник. Файлы не копируются на outreach; Яндекс Диск и его токены остаются под управлением исходной панели. Запись решений в ДСА, рассылки и новые кандидатские аккаунты не создавались.

## Проверка

44 серверных теста на outreach перед публикацией. Браузерная проверка выполняется по опубликованному HTTPS; её результат сохраняется в `output/playwright/dsa-candidates-result.json`. Снимки с персональными данными находятся в игнорируемой папке `output/playwright/dsa-candidates-private/`.

Опубликовано: API `20261006T074049Z`, UI `20261006T074110Z-7828`. Браузерных проверок: 58. Для каждого из шести кандидатов загружены метаданные записи, реально запущено воспроизведение и проверены переходы по таймкодам. Проверены смена короткой/полной версии, автоматический переход между фрагментами, профиль/резюме, 1440/390px, запрет доступа кандидатской роли. Ошибок JavaScript нет. Сценарий HR Vision остался revision 14 с прежним SHA-256; ответ API исходной панели ДСА до/после совпал.
