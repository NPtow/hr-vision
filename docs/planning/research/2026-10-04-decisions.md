# HR Vision: решения и границы, 4 октября 2026

## Подтверждено пользователем

- Сейчас работаем только с нанимающим менеджером.
- Вход через задачи найма, затем подборка выбранной задачи.
- Нет постоянного меню «Подборка / Встречи / Задача» и вопроса координатору.
- Встреча появляется после назначения.
- Нужен обязательный фидбек после интервью, затем оценка интервью, близкая к существующей панели. **Видеообъяснение отказа не входит в запрос.**
- Пул для оффера без ограничения числа людей. Офферы по очереди: отказ → следующий, принятие → остановка.
- Пользователь хочет отправлять оффер из аккаунта. Сейчас проектируем сторону работодателя; канал доставки и интерфейс кандидата не выбираем.
- Прямые понятные UI-правки выполняем. Для спорных решений сначала исследование и конкретный вариант, затем апрув пользователя, затем реализация.

## Что сделано в интерфейсе

Текущая история `hr-vision-product--manager`: задачи → подборка, без бокового меню и вопроса координатору; подтверждённая встреча открывается из контекста подбора. Сохранена имеющаяся структура списка и карточки. Это UI-просмотр с прежними демонстрационными данными, не подтверждение production-интеграции.

Отдельная галерея 10 альтернатив подборки создана по прямому поручению пользователя (`hr-vision-panel-alternatives--gallery`). Выбор варианта не означает автоматического внедрения в основной интерфейс.
