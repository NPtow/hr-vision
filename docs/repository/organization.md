# Организация HR Vision

Согласовано 28 октября 2026: один репозиторий, приложения в `apps/`, отдельные
серверные компоненты в `services/`, общие библиотеки в `packages/`, общая
инфраструктура в `infra/`. Перенос сохраняет поведение и действующие границы данных.

## Объём

1. Сохранить отсутствующие на GitHub исходники и локальные варианты в отдельных
   архивных ветках, без изменения исходных рабочих копий и их индексов.
2. Взять актуальный `origin/main` за основу общей версии. Новые приложения и
   прототипы добавить без перезаписи более свежих реализаций из `main`.
3. Перенести код, исправить пути и проверить сборки, упаковку и взаимодействия.
4. Опубликовать ветку и PR. Слияние и production-выпуск — отдельная операция.

## Границы

`recruiting-api` сохраняет авторизацию, согласия и продуктовые переходы.
`data-core` пока использует существующую HR-базу через адаптер: перенос папок
не создаёт независимого владельца этой базы. Старый `assessment` сохраняется
для его существующих потребителей. API, worker и scheduler одной функции
остаются внутри одного сервиса. Не добавляются новые распределённые вызовы,
брокеры или хранилища.

У каждого компонента остаются собственные зависимости и проверки. Общие
инструменты выпуска живут в `infra/deployment`; специфичные для сервиса
конфигурации могут оставаться в его `deploy/`.

| Публичное содержимое | Нет секретов, runtime-баз, записей интервью и приватных выгрузок в новых файлах | Индекс Git | PASS — проверены новые исходники и исключения |
