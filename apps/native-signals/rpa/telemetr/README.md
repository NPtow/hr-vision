# Telemetr RPA

Локальная надстройка над **сайтом** Telemetr. Не использует ключ Telemetr, REST/MCP API сервиса или перехват внутренних JSON-запросов. Основной проверенный путь использует уже авторизованную вкладку браузера Codex. Экспериментальный worker управляет отдельным Chrome for Testing (или установленным Chrome). Оба пути читают показанную страницу, а не скрытые сетевые ответы.

## Готовые блоки и выбор

- Playwright Core **1.64.0**, Apache-2.0: браузер, постоянный отдельный профиль, локаторы, ожидание элементов. [Документация](https://playwright.dev/docs/api/class-browsertype#browser-type-launch-persistent-context).
- Crawlee **3.18.2**, Apache-2.0: изучены RequestQueue, постоянное хранилище и ограничение частоты. Для одного сервиса текущая очередь меньше и прозрачнее на обычных атомарных JSON-файлах; Crawlee пока не добавлен. [Документация очереди](https://crawlee.dev/js/docs/guides/request-storage).
- Stagehand изучен как вариант восстановления действий через LLM. Для известной формы поиска он не нужен и добавляет стоимость вызовов модели. [Репозиторий](https://github.com/browserbase/stagehand).

Context7 использован по схеме resolve → docs для всех трёх. Точный поиск готового Telemetr-парсера через grep.app вернул 504; в веб-поиске подходящий поддерживаемый браузерный адаптер не найден. Это не утверждение об отсутствии таких проектов вообще. Специфичная разметка подтверждена на живом сайте 11.10.2026.

## Использование в приложении

«Поиск в Telegram → Через сайт · RPA» показывает сборы в открытом браузере Codex. Ключ API и повторный вход для проверенного прохода не понадобились. Сбор выполняется агентом во время работы с Codex; кнопка автономного запуска этого режима из macOS-приложения не реализована.

Каждая раскрытая карточка и каждая страница сохраняются в контрольную точку. `browser-import.mjs` проверяет query/период/порядок страниц/ID/ссылки/полноту и пишет атомарный экспорт + сводку прогресса; приложение автоматически импортирует экспорт через своё хранилище. Удалённые посты сохраняют архивный статус, показанный текст и ссылку на страницу поиска, без выдуманного оригинала. Медиа и комментарии не входят в сохранённый текст.

Сегментный сбор 0.7.2 поддерживает явный `captureMode: table`: все видимые строки сохраняются как фрагменты (`textFromCard: false`) без выдуманных исходных ссылок и статуса удаления. `capturedRows` содержит только проверенные раскрытые карточки и заменяет соответствующие фрагменты. Проверяются точный режим поиска, единственное/множественное число русского счётчика и разделители тысяч. Повторы между живыми страницами дедуплицируются и отражаются в квитанции; полнота сверяется с числом уникальных записей. Подтверждённый ноль требует сообщения «Ничего не найдено». `manifest.finished` завершает проход, но не превращает ограниченную выдачу в полную. Именованные сборы импортируются через прежнее хранилище; предел файла увеличен до 32 МБ.

Проверенный проход: 11.09–11.10.2026, три запроса, 7 страниц, 101 пост: Бруноям 6/6, karpov.courses 42/42, SETTERS Education 53/53. 75 каналов, 91 показанная ссылка на Telegram, 10 удалённых постов. Пример воспроизводимого импорта уже полученных страниц:

```sh
node rpa/telemetr/browser-import.mjs output/telemetr-browser-pilot-2026-10-11
```

Это повторный импорт локальных доказательств, не новый поиск. `manifest.json` задаёт запросы/период/ID; файлы `company-page.json` содержат DOM-снимок выдачи и раскрытые карточки.

Отдельный Chrome оставлен внутри «Экспериментального режима». Он получил 6 постов Брунояма, но потерял вход после перезапуска. Исправление сохранения собственной сессии покрыто локальным тестом, повторное живое восстановление входа пока не проверено. Worker остановлен; его очередь и результаты сохранены. Вход из Codex в другой профиль не копируется.

Для экспериментального worker одна очередь использует одну вкладку. Между карточками — 1 секунда, между страницами — 5 секунд. Это начальная консервативная настройка, не обещание допустимого сайтом темпа. Капча, ограничение, потеря входа, новая разметка, изменившиеся фильтры, повтор страницы — остановка с сохранением прогресса. Решение проверки в браузере вручную, затем «Продолжить». Ротации IP, обхода ограничений тарифа и фонового решения капч нет.

После каждой страницы сохраняется экспорт `TelemetrCollectionRun` с `origin=telemetrWebsite`. Приложение импортирует через существующее хранилище, сохраняя решения человека о связи с компанией. Одинаковые публикации внутри компании дедуплицируются по channelID + postID. Разные компании могут иметь один и тот же пост. Источник остаётся непроверенным до разбора.

`complete` означает достижение конца конкретной выдачи, не покрытие всего Telegram. Максимум страниц, недоступная следующая страница при большем счётчике и приблизительный счётчик сохраняются как partial. Дата публикации хранится строкой сайта; часовой пояс не придумывается. Текст из поисковой таблицы может быть сокращён.

## Локальный API

Сервер слушает только случайный порт `127.0.0.1`. Порт и локальный токен находятся в `~/Library/Application Support/TG Signals/rpa-telemetr/control.json` с правами 0600. Запросы с Origin отклоняются; HTTP API не публикуется в сети. Ключ Telemetr не нужен.

- `GET /status` — состояние браузера и последние сборы.
- `POST /browser` — открыть браузер для входа/проверки.
- `POST /jobs` — `{queries:[{companyID,companyName,query}],dateFrom,dateTo,maxPages}`.
- `POST /jobs/{id}/pause` — остановиться с сохранением уже собранных страниц.
- `POST /jobs/{id}/resume` — продолжить, включая восстановление после перезапуска.

Для всех методов нужен `Authorization: Bearer <локальный токен>`. Контрольный файл не выводить в терминал/отчёты. Локальная папка содержит профиль браузера (чувствительные данные), журналы и экспорты. Не переносить её в репозиторий.

## Разработка

Требуется Node.js (`/opt/homebrew/bin/node` или `/usr/local/bin/node`) и браузер. `npm ci --ignore-scripts`, затем `node node_modules/playwright-core/cli.js install chromium --no-shell` устанавливает официальную совместимую сборку Chrome for Testing. Если её нет, используется установленный Google Chrome. `npm test`. `node server.mjs` запускает worker; для изоляции тестов можно указать `TG_SIGNALS_RPA_DIR`. В macOS-приложение модуль включается `scripts/build-app.sh`. Сборщик запускается по кнопке, не автоматически при старте Mac.


11.10.2026 в профиле оплаченного аккаунта проверено: «Эконом», поиск постов — 100 запросов в день, глубина тарифа — 3 месяца. Конкретные лимиты могут меняться; очередь не обещает обработать 409 компаний за один день.
