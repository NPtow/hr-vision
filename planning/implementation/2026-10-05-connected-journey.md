# Связанный тест HR Vision · 5 октября 2026

Согласовано в чате: outreach, одна задача, один работодатель и три кандидата. Готовые аккаунты, серверные действия между устройствами, общий сброс. Кандидат видит подходящую вакансию и выбирает интерес до показа работодателю. Автоматический режим принимает вакансии, первая встреча всегда подтверждается кандидатом вручную. Слоты задаёт кандидат; pending/confirmed встречи занимают время. Настоящий встроенный звонок, запись, транскрипт; оценка отдельно помеченная заглушка. Фидбек работодателя обязателен, кандидат отмечает интерес после встречи. Пул без лимита, один активный оффер, принять/отклонить/обсудить в чате; принятие завершает найм. TG и демонстрация экрана вне текущего шага.

Реализация: независимый сервис Python/SQLite на outreach, существующая статическая площадка и UI-компоненты. Бизнес-переходы выполняет сервер; аккаунт и выбор экрана принадлежат вкладке. Общая ссылка команды является ключом доступа к тесту, не публичной регистрацией. Только вымышленные профили. Подключение видео: адаптер Daily Prebuilt; платные операции отключены до настройки серверного API-ключа и явного включения. Проверки UI по публичному HTTPS, без localhost на компьютере.

Текущий статус: Daily подключён вечером 05.10.2026, фактическая проверка звонка/записи/русской расшифровки описана в конце документа. Ни новый аккаунт, ни новый тариф не оформлялись. Ниже сохранены результаты первоначального прохода до подключения.

## Результат первоначального прохода

Опубликованы связанный API и UI. API release 20261005T101030Z; UI release 20261005T101029Z-21537. 15 доменных тестов, 20 HTTP проверок и 17 браузерных проверок. Общий сценарий сброшен в исходное состояние перед передачей. Реальный медиа-сеанс остаётся непроверенным до Daily account/API key. Текущий сервер сообщает videoConfigured=false, платные обращения отключены.

Daily: https://www.daily.co/pricing/video-sdk/ (проверено 05.10.2026): 10,000 participant-min video free/month; recording $0.01349/min + storage $0.003/min; realtime transcription $0.0059/unmuted participant-min. Пример 10 × 60 минут × 2 участника: ~$16.97 при неиспользованной бесплатной квоте видео, без других продуктов/налогов. Это оценка usage, не фиксированный тариф. SDK встроен на нашем URL; запись и transcript получаются через серверный API. Нужна проверка реального аккаунта/доступности платных возможностей.

## Восстановление видео-разбора, 5 октября, 13:48 МСК

UI release `20261005T104539Z-17259` на outreach. При переходе к серверному сценарию интервью оказалось во вторичной вкладке, а разбор после встречи был заменён упрощённым блоком. Исправлено: карточка работодателя по умолчанию открывает первичное интервью; плеер и фрагменты расположены рядом; действия перенесены под имя, не перекрывают запись. Из встречи есть прямой возврат к первичному интервью. Вернулась проверка плеера локальным файлом в инструментах команды.

Общий плеер теперь имеет доступный с клавиатуры таймлайн и маркеры. После обязательного фидбека отдельный экран показывает запись конкретной встречи, WebVTT-фрагменты, расшифровку, фидбек и явно обозначенную заглушку оценки. Первичное интервью не используется как запись встречи. Состояние отсутствующих материалов видно даже без Daily. Нет выдуманной длительности, таймкодов или автоматических баллов. Несколько файлов записи не связываются с одним отсчётом времени без проверенного соответствия.

Проверки: 21 браузерная проверка связанного интерфейса, 19 регрессионных проверок плеера старой галереи, 9 проверок разбора WebVTT. Типы, сборка, публикация и `git diff --check` прошли. Десктоп 1440px и мобильный 390px осмотрены. Живой сценарий команды не сбрасывался и не менялся: проверка на сервере была только чтением. После встречи использовались изолированные браузерные ответы API и техническое видео, не выдаваемые за реальный Daily-сеанс. Отчёты в `output/playwright/video-review-*-result.json`.

Daily по-прежнему `videoConfigured=false`; серверный ключ отсутствует. Кабинет провайдера открыт на странице входа. Нужен вход пользователя в Daily для последующего подключения; аккаунт не создавался, оплат не было.

## Подключение Daily и реальная проверка, 5 октября, 22:03 МСК

Использован существующий аккаунт `mashadasha.daily.co` и его существующий API-ключ. Секрет сохранён только в root/600 env на outreach; временная локальная копия удалена. `videoConfigured=true`. Платёжные настройки не менялись. API release `20261005T184847Z`, UI release `20261005T190322Z-27519`.

Исправлены восстановление/продление комнаты после повторного входа и сбоя выдачи токена. Добавлены семь provider tests к 15 доменным. На фактическом WebVTT Daily обнаружен второй формат имени говорящего (`<v>Имя:</v>Речь`), он поддержан без склейки имени с текстом; десять parser checks прошли.

На публичном HR Vision два браузерных участника вошли в реальную Daily-комнату. Камеры синтетические, русская речь сгенерирована для проверки. В обе стороны измерен ненулевой входящий звук, отображаются по две видеодорожки. Первый прогон с Chromium fake-file microphone дал тишину и пустой VTT; он не считается подтверждением транскрибации. Повторный прогон с явной Web Audio дорожкой дал сохранённую запись и 71 фрагмент русской речи обоих участников.

Текущий API-код завершил и прочитал материалы QA-встречи в отдельной временной SQLite на outreach; повторная выдача комнаты после завершения вернула 409. В опубликованном UI реальная запись воспроизводится, фрагменты перематывают плеер, 1440/390px проверены. Бизнес-состояние для этого браузерного медиа-теста изолировано. Это не новый полный регрессионный прогон всей воронки и не проверка физических устройств людей. Живая встреча пользователя осталась подтверждённой; общий тест не сбрасывался. Отчёт: `output/playwright/daily-connected-result.json`.

## Полный экран звонка и обязательный фидбек 5 октября вечером

UI release `20261005T195317Z-28090`, API release `20261005T194734Z`. Звонок переведён в viewport overlay с недоступным фоновым интерфейсом, отдельным завершением работодателя и выходом кандидата. После серверного завершения автоматически открывается очередь обязательных анкет всех завершённых встреч; обновление страницы не уводит от незавершённого фидбека. Фокус установлен на заголовок. Черновики и версия вопросов сохраняются на сервере, ответы привязаны к meetingId; старые отзывы сохранены без миграции.

Вопросы теперь извлекаются из фактических финальных реплик интервьюера Daily; резервно используются готовые WebVTT, а при отсутствии материала интервьюер может указать заданные вопросы сам. Фиксированные темы анкеты не используются для новых встреч. Извлечение детерминированное, не LLM. Ошибки распознавания/необсуждавшийся вопрос можно отметить явно; автоматическую оценку кандидата это не реализует.

34 серверные проверки прошли, включая HTTP во временной SQLite на outreach. 24 браузерные проверки прошли на опубликованном HTTPS с реальным Daily и синтетическими камерой/русской речью; состояние найма изолировано браузерными ответами API. Проверены полный viewport обеих ролей, две видеодорожки, отсутствие преждевременной формы, автоматическое завершение у кандидата, фокус, серверный контракт черновиков, UI восстановление, очередь и отсутствие стандартной анкеты при задержке транскрипта. Исходный live scenario не сбрасывался. Отчёты трёх агентов и закрытие замечаний: `output/design-review-2026-10-05/README.md`.
