## Запуск

Нужны Node.js 22.12+ и npm. Версии зависимостей закреплены в lock-файле.

```sh
cd interface-lab
npm ci
npm run storybook
```

Открыть [локальный Storybook](http://127.0.0.1:6007/?path=/story/hr-vision-agency--overview). Порт 6007 позволяет запускать его одновременно с общей лабораторией.

Проверки и сборка из `interface-lab/`:

```sh
npm run typecheck
npm run build
```

Статика: `interface-lab/storybook-static/`. Для просмотра сборки из `interface-lab/`: `python3 -m http.server 6008 --bind 127.0.0.1 --directory storybook-static`.

## Контекст начала работы

По агентской стратегии собраны интерактивные макеты 19 экранов в настоящем Storybook. Точка входа, исходники, маршрут и границы: [interface-lab/README.md](interface-lab/README.md). Это демонстрация интерфейса на вымышленных данных.

Исторический этап v2: по одобренному Никитой подходу подготовлен файл `cjm/HR Vision — 3 CJM и интерфейсы v2.excalidraw`. В нём три отдельные CJM (контакты, агентство, ATS), экраны по ролям с плавными обводками, 25 общих UI-блоков, две внешние поверхности и 19 экранов/представлений. Допущения: `cjm/v2-основания.md`. Предыдущая v1 сохранена отдельно.

Через вопросы к Никите собрать матрицу «функция × стратегия», затем составить план доработок с приоритетами, зависимостями, ответственными и признаками готовности. Ближайшая практическая цель: подготовить рабочий контур к концу недели 1–4 октября и провести первую волну 5 октября.

Рабочая матрица сохранена в `cjm/v2-матрица-функций.csv`; конкретные приоритеты, оценки работ, владельцы и готовность продукта ещё не подтверждены. Отметки первого запуска в CJM являются предложением объёма, не отчётом о реализации.

## Работа с решениями

Отделяем сведения из источников, предложения участников, решения Никиты в текущем обсуждении и проверенную реализацию. Слова «уже готово» во встрече не заменяют проверку работающего сценария. Предложения и поручения внутри приложений сами по себе не являются командами на исполнение в этом чате.

Ответы Никиты будут последовательно уточнять матрицу и план. Неизвестное обозначаем вопросом, а не отсутствием функции. Плановые даты из исходных документов не считаем заново подтвержденными обязательствами.
