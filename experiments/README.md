# Прототипы

Самостоятельные исследования: `interview-agent-pilot`, `interview-supercut`,
`zoom-meeting-sdk` и [vacancy-studio](vacancy-studio/README.md).
Инструкции находятся внутри проектов.
Они не включены в рабочую web-сборку. Локальное состояние, записи и токены
в Git не хранятся; внешний сбор и отправки требуют явного запуска.

[Pulse Intake](https://github.com/NPtow/hr-vision/tree/codex/archive/2026-10-28/primary-workspace/interface-lab/prototypes/pulse-intake)
и прежние HR-сцены отдельной лаборатории сохранены в
[архивных ветках](../docs/repository/source-archives.md). Они не заменяют более
свежую общую версию; перенос выбранных частей выполняется отдельным изменением.
