# YC: результат первого запуска готового агента

Проверено 25 октября 2026, 21:55 МСК. Пять последовательных запросов на синтетических
данных выполнены на существующем YC-сервере outreach. Каждый запрос запускался в
новом контейнере; между ними сохранялись только файлы сессии.

**Итог:** Strands Harness работает через текущий CLIProxyAPI, вызывает существующий
поиск Jev, сохраняет контекст разговора после пересоздания процесса и разделяет
сессии кандидатов. Это подтверждение совместимости и нескольких сценариев,
не результат сравнения качества со старым помощником на реальных интервью.

- Выполненный код: `60188b53`, образ `hr-agent-pilot:60188b53`.

- Jev: фактически ответил `jev-1.14.0`; три вызова действующего адаптера поиска.
- Сам агентный цикл, выбор инструментов и восстановление сессии — из пакета Strands.
  HR-адаптер предоставляет пять инструментов чтения и сохраняет результат проверки.
- Память контейнера ограничена 512 MiB, CPU — 0.7, число процессов — 128.
- Нет опубликованного порта и постоянно работающего процесса пилота. Снимки бесед и
  приватная конфигурация сохранены вне каталога релиза для следующего теста.

## Что ещё не проверено

Интерфейс помощника пока не подключён к этому пилоту. Не проверены реальные длинные
интервью, сжатие переполненного контекста, восстановление после перезагрузки браузера,
стриминг в UI, остановка и повторы запросов, отзыв доступа, конкурентные сессии,
общая память между разными беседами и сравнение со старым помощником на одной модели.
