## Уже внесено в ProfileInterview.tsx

1. `SkillVideo` открывает полный разговор на фактическом `video.currentTime`. До этого использовалось последнее состояние React: между событиями `timeupdate` позиция отставала. Проверенный пример: было открытие на 16.00 вместо 19.75 секунды.
2. Короткий плеер слушает существующее событие `hr-vision-interview-play` и останавливается, когда играет другой плеер. При уходе слушатель удаляется и клип останавливается. Раньше короткое видео лишь отправляло событие, но не слушало его.
3. `FullInterview` реагирует на изменение входного `initialSeconds` без перемонтирования. Смена навыка в раскрытом профиле теперь переводит плеер к выбранному моменту. Проверенный пример: 8 → 24 секунды раньше оставался на 8.

Изменён только вспомогательный модуль видео. Перед записью сверил SHA-256: конкурентных изменений в нём не было. Копия до изменения и diff сохранены в `output/candidate-profile-support-20261026/`.

## Обнаруженная несовместимость публичного чата — воспроизведена, не применена к сервису

Рабочая копия: `/Users/NIKITA/.codex/worktrees/employer-task-states/HR Vision/interface-lab/`.

`src/scenes/candidate-portal/PublicCandidateProfile.tsx` отправляет `recordingId` в `/api/hr/public-profile/assistant`.
`server/public_profiles.py` этой версии допускает ровно `token`, `action`, `query`, `requestId`. Поэтому запрос из текущего UI получает 400 до вызова ассистента. Сервер сам привязывает единственную запись и транскрипт к capability.

`output/candidate-profile-support-20261026/public-assistant-contract.json` содержит воспроизведение 400 → 200 на временной БД и mock ассистента. Токены не сохранены.

Подготовлен `public-assistant-v1-compatibility.patch`: убирает лишнее поле из UI. Патч не применён — текущий тред работает над макетом, а состояние выкладки сервиса не проверялось. Использовать только с зафиксированным single-recording API. Для нескольких записей нужна согласованная новая серверная схема с проверкой принадлежности выбранной записи; нельзя просто разрешить произвольный recordingId.

## Важная граница кнопки «Поделиться»

Текущий API создаёт/отзывает доступ к профилю с резюме и завершённым интервью. Он не принимает выбранные навыки, отдельные фрагменты или маску полей. Чекбоксы макета — только локальный предпросмотр, пока такие ограничения не поддержаны сервером. Нельзя представить скрытый в UI раздел как недоступный по публичному API.
