## Повторить проверку

После запуска Storybook из `interface-lab`:

```sh
npx @playwright/cli --session xpm-check open 'http://127.0.0.1:6007/iframe.html?id=hr-vision-xpm--overview&viewMode=story'
npx @playwright/cli --session xpm-check run-code "$(cat scripts/xpm-render-check.js)"
```

Для WebKit открыть отдельную сессию с `--browser webkit` (движок должен быть установлен). Скрипт возвращает `passed: true` либо ошибку с найденными дефектами. Помимо него нужен визуальный просмотр подписи при изменениях шрифта, слоёв или масштаба; геометрия сама по себе не доказывает качество глифов.
