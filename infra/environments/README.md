# Окружения

`local`, `staging` и `production` обозначают конфигурацию запуска. Исходники
выбираются по commit SHA; одинаковая версия может проверяться в разных средах.
Образцы переменных находятся рядом с потребителем. Рабочие значения хранятся
вне Git и передаются процессу существующим способом.

Этот перенос не создаёт новый staging-сервер. Существующие GitHub Environments
для web/API называются `service` и `mockups`; их секреты и права сохраняются.
Для повторения релиза используйте его commit SHA и manifest упаковщика.
