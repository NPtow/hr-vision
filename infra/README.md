# Инфраструктура

- [deployment/web](deployment/web): web/API, provision-скрипты и ограниченный deploy receiver.
- [deployment/services](deployment/services): упаковщики независимых сервисов, lock-файлы и инструкции.
- [observability](observability/README.md): сбор и просмотр телеметрии.
- [environments](environments/README.md): конфигурация окружений.

Перенесены исходники инструментов; пути на серверах и формат архивов сохраняются.
Не запускайте provision/install-скрипты ради локальной проверки: они предназначены
для конкретной серверной среды. Используйте `python scripts/check.py`.

Публикация web/API выполняется вручную workflow `Deploy HR Vision`. Он собирает
и проверяет разрешённую ветку, упаковывает UI/API, отправляет архив через
существующий ограниченный SSH receiver и сверяет ревизию. Независимые сервисы
выпускаются их собственными упаковщиками. Локальные проверки не заменяют
проверку сервера после разрешённого выпуска.
